01　阅读主干

保留原句的每个字，主干沿阅读顺序推进。二维布局只调整显示关系，不替换原始文字。

阅读页「逐句 / 合段」可切换 · 导出保留源文本
∧语音编码词汇提取语义整合
:::and

02　与 / 及 / AND / ^ / ∧

“和、与、及”归入并取（AND）关系；文字记号与 ∧ / ^ 记号只是显示形式不同。位置可选括线中央，或倒数第二个实际并列项之后（不计“...”）。

选区 → ∧　 ·　可调线宽与颜色
∨中文阅读English...
:::or

03　或 / OR / ∨ / v

选言与并取分别编码。“或 / OR / ∨ / v”是可切换的视觉记号；也可放在括线中央或倒数第二个实际并列项之后（不计“...”）。默认不推断为互斥。

选区 → ∨　 ·　“...” 留在括线内，但不参与并列项计数
−单纯视觉接收＋复杂信息加工
:::contrast

04　对位 / 否定 → 肯定

“并非”“而是”对应各自的行，不悬浮在整个容器的顶端；上下排列以降低对比成本。

选区 → ⇄　 ·　关系符号随行定位
对于阅读障碍者而言阅读困难可能源于……
:::preface视觉节点

05　前置从句 / 脚标

前置限定语采用小字号、靠近主句左下方的脚标排法。一般从属语也可以沿括线下挂。

缩放比例在「阅读版式」中可调
∧甲乙丙...
等 → ...

06　去噪，非删除

“、”“，”“和”“与”“及”“或”等在有明确结构时从视觉层淡出；标点不浮现。“等”化为 ...，显示在并列括线内的末行，但只是省略占位符，不是真正的并列项。

AST 仍存储原文标点和虚词 · 保真校验

foreign / inline · bubble · ruby

07　外文注记

行内彩色、上浮气泡、仿假名上标三种显示方式。上标英文可向两侧溢出并调整留白；遇到 RAN 这类缩写时，可叠在英文之上，或用「·」接在汉语、英语词后。英文源文本不变。

「样式 → 外文注记」切换
▤→阅读轨迹
linear / preview

08　阅读辅助

马克笔始终在文字底下。顺序模式连续扫过；「先总览」会先短暂点亮并列组各行，再沿顺序逐项划出。

「阅读 → 注意力偏好」可调停驻时长

09　标记语言草案

:::and、:::or、:::contrast、:::sub 是计划采用的结构块；<> 共享槽位可按行 zip 或组合 product 展开。
